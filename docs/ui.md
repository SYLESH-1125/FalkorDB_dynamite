The frontend should be a modern, government-grade enterprise dashboard application — clean, data-dense but not cluttered, evoking trust, authority, and precision (think a hybrid of a NIC/Digital India portal and a modern SaaS analytics tool like Notion + Tableau). Use a sidebar-based layout: a fixed left navigation sidebar (collapsible) listing all modules — Dashboard, Document Upload, Data Validation, AI Query System, Report Generation, Word Cloud/Topics, Report Archive, Parliamentary Tracker, Analytics, User Management, Audit Log, Settings — each with a simple line icon and label, with the active item highlighted. Top bar should have the CMPDI/CIL logo + title on the left, a global search bar in the center, and notifications/profile dropdown on the right. Color palette: deep navy/blue (
#0B2545 or similar) and white as primary, with a coal-industry accent (amber/orange or a slate gray) used sparingly for CTAs and status indicators — avoid overly playful colors, keep it formal/institutional. Typography should be clean sans-serif (Inter or similar), strong hierarchy between headers, section titles, and body/table text.

Every content page should follow a consistent template: a page header with title + breadcrumb + primary action button (e.g., "Upload Document", "Generate Report") on the right, followed by content in card-based panels with soft shadows and rounded corners (8-12px radius), consistent 16-24px spacing/grid. Use tables with sticky headers, sortable columns, status badges (color-coded: green=validated, amber=pending, red=error) for document/report listings. The Dashboard page should show KPI stat cards at top (reports generated, avg. processing time, accuracy %, pending queries) followed by charts (bar/line/pie using a library like Recharts) for trends, and a recent activity feed. The Upload page needs a drag-and-drop zone plus a progress-tracked file list with per-file status (uploading/processing/validated/error). The AI Query page should look like a chat interface (message bubbles, input box with send button, suggested/quick-query chips) with citations/source references shown as expandable cards below AI responses. The Report Generation page should have a step-based wizard (select data sources → choose template → configure parameters → preview → export as PDF/Word). The Word Cloud/Topic module should show an interactive word cloud visualization alongside a topic-frequency bar chart. Use skeleton loaders for async states, toast notifications for actions, and modals for confirmations/detail views. Ensure full responsiveness down to tablet width, with the sidebar collapsing to icons-only or a hamburger drawer on smaller screens. Accessibility matters — sufficient contrast, focus states, and readable font sizes throughout, since this is a government platform used by officials of varying technical proficiency.

The frontend should merge Sarvam AI's warm, premium "sovereign platform" aesthetic with a Power BI-style analytics workspace. The landing/dashboard background should use soft, large-radius blurred gradient blobs (burnt-orange/amber transitioning into pale blue-lavender, fading to off-white) sitting behind a mostly white/cream canvas — never full-bleed color, just a glow concentrated near the top and corners of the page. The top navbar should be a pill-shaped, floating cream/beige bar with rounded full corners, holding the CMPDI/CIL wordmark on the left in a bold modern sans-serif, center nav links (Dashboard, Reports, Query System, Word Cloud, Analytics) in small-caps gray text, and two pill-shaped CTA buttons on the right — one solid deep-navy ("Login"/"New Report") and one white-outline ("Contact/Help"). Headlines throughout should mix a large elegant serif display font (like the "AI for all from India" treatment) for section titles with a clean grotesque sans-serif for body copy and data labels, giving a sovereign, editorial-yet-technical feel rather than a generic SaaS look. Below this branded shell, the actual working screens (Dashboard, Report Generation, Analytics, AI Query) should shift into a dense Power BI-style layout: a left filter/slicer rail (date range, subsidiary/state, mine type, report category as dropdown chips), a canvas of draggable/resizable card panels containing KPI tiles with large bold numbers and small trend arrows, cross-filterable bar/line/donut charts, a matrix/pivot-style data table with conditional-formatting color scales, and a persistent "Ask a question" natural-language query bar pinned at the top of the analytics canvas (Power BI Q&A style) that lets users type queries and get auto-generated charts/answers. Cards should have the same soft rounded corners and subtle shadow as Sarvam's UI but sit on a light gray-white dashboard background (not the gradient) once inside the app, with the gradient glow reserved for the landing, login, and section-header hero strips to keep the dense data screens readable; accent color for charts/highlights should pull from the same amber-orange used in the Sarvam hero, paired with navy and neutral grays for a cohesive, government-sovereign-tech identity.
