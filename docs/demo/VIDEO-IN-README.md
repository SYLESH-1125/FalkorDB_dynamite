# Inline video in the GitHub README (one-time)

GitHub **does not** show an inline `<video>` player for repo-hosted MP4 files in most README views. These work:

1. **Click-to-play (current default)** — poster image links to the file page, which has GitHub’s native player:  
   [project-selection-graph-solution.mp4](https://github.com/SYLESH-1125/FalkorDB_dynamite/blob/main/docs/demo/project-selection-graph-solution.mp4)

2. **True inline player in README** — on github.com, edit `README.md`, drag this MP4 into the editor where the video should appear, commit. GitHub replaces it with a `https://github.com/user-attachments/assets/...` URL that autoplays inline.
